# Day 41: Project Ideation & Design Doc

## Learning Goals
- Brainstorm and select a capstone project that applies GenAI concepts learned.
- Write a structured design document (project scope, tech stack, milestones).
- Justify your choice with clear goals and success metrics.

## Topics Covered
1. Ideation techniques for GenAI projects (chatbots, art tools, RAG systems, agents, etc.).
2. Components of a design doc: problem statement, solution overview, user stories, technical architecture, data requirements, evaluation plan.
3. Milestone planning for the remaining 9 days.

## Project Ideas
- **RAG-powered research assistant** for internal documents.
- **Multimodal search engine** (text + image) with CLIP and FAISS.
- **AI art generator with ControlNet** (sketch-to-image).
- **Multi-agent debate system** for decision support.
- **Personalised chatbot** with long‑term memory.
- **Code assistant** for a specific framework.
- **Audio/music generator** with user‑controlled style.

## Deliverable
By end of day, submit a Markdown design document (`DESIGN.md`) with:
- Project title and one‑line description
- Target users and use cases
- Core features (list)
- Tech stack (models, libraries, deployment)
- Data sources (if any)
- Evaluation plan (how you measure success)
- Timeline for days 42–50
