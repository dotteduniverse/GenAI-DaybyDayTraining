# Exercises – Day 40

1. **Change personas**  
   Design two new agents: one “realist” and one “futurist”. Run the same question and compare the debate outcome.

2. **Add a third agent**  
   Extend the system to three agents (e.g., optimist, pessimist, neutral). Have them debate in a round‑robin order.

3. **Convergence condition**  
   Stop the debate early if the last two answers from each agent are very similar (use embedding similarity). Implement this.

4. **Topic: controversial question**  
   Use a polarising question like “Is social media beneficial for society?”. Observe how the judge synthesises extremes.

5. **Bonus: Self‑critique**  
   After the judge produces a final answer, ask the judge to reflect on potential weaknesses and refine the answer again (one more loop).
