# Exercises – Day 50

1. **Record your demo video**  
   Use OBS, Loom, or QuickTime. Follow the demo script. Keep it under 5 minutes. Upload to YouTube (unlisted) or Loom.

2. **Create your presentation**  
   Convert the slide outline into actual slides (Google Slides, PowerPoint, or Canva). Include screenshots and a link to the live demo.

3. **Update your GitHub repository**  
   Ensure all code is pushed, README is polished, and links (demo video, blog, live app) are present. Add a license file (e.g., MIT).

4. **Submit your project**  
   Share the following with your mentor/classroom:
   - GitHub repo URL
   - Live demo URL
   - Demo video URL
   - Blog post URL (optional but encouraged)

5. **Bonus: Prepare a lightning talk**  
   Write a 60‑second summary of your project. Practice delivering it without slides. Record it as a separate short video.
