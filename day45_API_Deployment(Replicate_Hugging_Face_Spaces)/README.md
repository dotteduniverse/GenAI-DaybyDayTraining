# Day 45: API Deployment (Replicate, Hugging Face Spaces)

## Learning Goals
- Deploy your GenAI capstone project as a public API or web app.
- Use Hugging Face Spaces for a hosted Gradio/Streamlit app.
- (Optional) Use Replicate to deploy a model with a simple API.

## Topics Covered
1. Hugging Face Spaces: free hosting for Gradio/Streamlit.
2. Creating a `requirements.txt` and `app.py` for Spaces.
3. Deploying from GitHub or directly uploading.
4. Replicate: cog-based deployment for scalable model inference.

## Setup
- Hugging Face account (huggingface.co)
- (Optional) Replicate account (replicate.com)
