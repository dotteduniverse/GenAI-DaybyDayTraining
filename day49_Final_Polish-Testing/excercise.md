# Exercises – Day 49

1. **Run user tests**  
   Recruit at least 2 people (friends, classmates) to test your deployed app. Use the feedback form. Document at least 3 pieces of feedback.

2. **Fix critical bugs**  
   From the feedback or your own testing, identify the 2 most serious issues. Fix them and verify the fix.

3. **Add error handling**  
   Add try/except blocks for external API calls (OpenAI, etc.). Display user‑friendly error messages instead of raw exceptions.

4. **Write unit tests**  
   Write at least 2 unit tests for core functions (e.g., text preprocessing, API call simulation, embedding generation). Run `pytest` and report results.

5. **Bonus: Cross‑browser testing**  
   Test your Gradio/Streamlit app on Chrome, Firefox, and Safari. Report any layout differences or JS errors.
