# Day 49: Final Polish & Testing

## Learning Goals
- Conduct structured user testing to uncover usability and functional issues.
- Prioritise and fix critical bugs.
- Optimise performance, handle edge cases, and improve error messages.
- Prepare the project for final showcase.

## Topics Covered
1. Types of testing: unit tests, integration tests, manual user testing.
2. Creating a test plan and feedback form.
3. Bug tracking and prioritisation (critical, major, minor).
4. Final polish: logging, error handling, documentation.
5. Regression testing after fixes.

## Setup
No new libraries; use `pytest` for unit tests if applicable.
